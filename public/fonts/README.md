# Fonts

CMU Serif and CMU Typewriter Text (Computer Modern Unicode), the default LaTeX typefaces,
unmodified woff2 files from the `computer-modern` npm package (0.1.3,
https://github.com/stevenpetryk/computer-modern). Licence: SIL Open Font License 1.1, see
`OFL.txt`. Computer Modern by Donald Knuth; CMU by Andrey V. Panov.

`assets-og/cmu-serif-500-roman.ttf` (same source) is used only server-side by
`app/opengraph-image.tsx`.
